# BulkTrack identity

Created with the built-in image generation tool, October 15, 2026.

The mark combines an ascending strength path with a geometric B. Deep forest teal and pale lime match the app's existing palette. The square, opaque background is masked by iOS on the Home Screen.

## Files

- **BulkTrack-logo-original.png** — generated master, 1254 × 1254, opaque RGB.
- **../BulkTrack/Assets.xcassets/AppIcon.appiconset/AppIcon.png** — 1024 × 1024 iOS app icon.
- **../BulkTrack/Assets.xcassets/BulkTrackMark.imageset/BulkTrackMark.png** — 256 × 256 in-app branding asset.

The generated master is copied into the project. The packaged icon and header asset are resized derivatives prepared with macOS sips.

## Final generation prompt

Use case: logo-brand. Create one finished, production-ready iOS app icon for BulkTrack, a fitness, strength and healthy weight-gain tracker. Square 1024 by 1024 image, completely opaque. Full-bleed deep forest teal background matching hex #173E32, with an extremely subtle lighter teal gradient. Center a bold, original geometric monogram combining a capital B with three ascending rounded steps / a rising strength path, in luminous pale lime #D9F99A. The result should look like a premium contemporary fitness brand, simple and confident, flat vector-like edges, balanced generous space, strong silhouette recognizable at 40 pixels. One cohesive custom symbol, not a generic dumbbell, not a leaf. Symbol occupies about 65 percent of square. No text, no wordmark, no border, no outer rounded corners, no photographic mockup, no phone, no watermarks, no grid of variations. iOS applies the icon corner mask itself; background must fill all four square corners.
